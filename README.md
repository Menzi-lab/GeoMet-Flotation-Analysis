# GeoMet Flotation Analysis

## Project Overview

This project explores geometallurgical data to investigate relationships between elemental assays, flotation variables, and drillhole measurements. The analysis uses Python for data cleaning, exploratory data analysis (EDA), statistical summaries, and visualisation.

## Objectives

- Explore copper (Cu), iron (Fe), and sulphur (S) assay distributions.
- Investigate the distributions and variability of the flotation variables `fr`, `xr`, and `LCT`.
- Examine correlations and potential relationships between elemental assays and flotation indicators.
- Generate visualisations to support further metallurgical investigation.

## Dataset

The project uses geometallurgical datasets containing flotation, drillhole, and comminution information.

The dataset source is [Zenodo — GeoMet dataset](https://zenodo.org/records/7051975).

## Tools and Technologies

- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Statistical and exploratory data analysis

## Repository Structure

- `Data/` — source datasets and supporting documentation
- `figures/` — visualisations generated during the analysis
- `Flotation_Drillholes_EDA_.ipynb` — main analysis notebook

## Key Outputs

The project generates grade distributions, flotation-variable distributions, correlation plots, scatterplots, and comparisons between flotation variables and drillhole assays.

## Limitations

The focused flotation dataset contains 53 records. Findings are exploratory and should not be interpreted as conclusive evidence of causation or plant-scale performance. Variable definitions and metallurgical interpretations should be verified against the dataset documentation.

## Reproducibility

To reproduce the analysis, clone the repository, install the required Python libraries, and run the notebook in Jupyter Notebook or VS Code.
